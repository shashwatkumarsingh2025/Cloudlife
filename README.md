# ☁️ CloudLife

## Cloud-Based Personal Life Management System

CloudLife is a cloud-based application that helps users manage their daily tasks, expenses, notes, and events from a single dashboard.

## 🏗️ Project Architecture

Frontend:
- HTML
- CSS
- JavaScript

Backend:
- Node.js
- Express.js
- REST APIs

Cloud Database:
- Supabase PostgreSQL

API Documentation:
- Swagger UI

Deployment:
- Render
